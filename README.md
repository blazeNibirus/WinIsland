## ✨ Что умеет

| Возможность | Описание |
|---|---|
| 🏝️ **Два вида** | Капсула (как iPhone 14 Pro) или **чёлка** (как iPhone 13, с динамиком и камерой). Переключается в меню в трее |
| 🎵 **Плеер** | Обложка, название, перемотка, пауза, следующий/предыдущий трек (Spotify, Яндекс Музыка, YouTube в браузере…) |
| 🔔 **Уведомления** | Telegram, WhatsApp и другие уведомления Windows появляются в острове плавным баннером |
| ⏱️ **Таймер и секундомер** | Как на iPhone: кольцо, кнопки «Старт/Пауза/Отмена», в свёрнутом острове — мини-таймер |
| 📝 **Заметки** | Быстро записать мысль прямо из острова |
| 🧭 **Вкладки** | Сверху раскрытого острова панель: Медиа · Быстрые настройки · Таймер · Заметки |
| 🖥️ **Полный экран** | Остров сам прячется, когда открыто полноэкранное приложение (включается в трее) |
| ⬇️ **Загрузки** | Процент, скорость, после 100% остров держит галочку пару секунд и красиво прячется |
| 🌤️ **Погода** | Клик по погоде — поиск и выбор любого города |
| ⚙️ **Быстрые настройки** | Wi-Fi, Bluetooth, режим полёта, «без звука», громкость, яркость — значки в стиле Apple |
| 📎 **Полка для файлов** | Перетащите файл на остров, потом вытащите обратно куда нужно |
| ⏱️ **Задержка закрытия** | Остров закрывается через 1–60 секунд после ухода мыши (по умолчанию 10) |
| 🎬 **Анимации** | Пружинные, плавные, как у Apple |

## 🚀 Установка

1. Установите [Python 3.10+](https://www.python.org/downloads/) — на первом экране установщика **обязательно поставьте галочку «Add python.exe to PATH»**.
2. На этой странице нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.
3. Запустите `install.bat` (один раз, дождитесь надписи «Готово»), затем `run.bat`.

Остров появится сверху экрана, а значок — в трее (рядом с часами). Если не появился — запустите `run_debug.bat`, он покажет ошибку.

> 📦 В разделе **Releases** (справа на странице) появляются выпущенные версии: там лежит тот же архив `WinIsland-source.zip`,
> а иногда ещё и `WinIsland-windows.zip` с готовым `WinIsland.exe` (Python не нужен).
> Если Releases пока пустой — просто используйте шаги выше, они работают всегда.

## 🖱️ Как пользоваться

- **Наведите мышь** на остров или кликните — он раскроется. «Медиа» всегда открывается первой.
- Маленькие кнопки вверху — переключение вкладок: **Медиа · Быстрые настройки · Таймер · Заметки**.
- **Правый клик** по острову или по значку в трее — меню настроек.
- Клик по погоде — **выбор города**.
- Колесо мыши на вкладке «Заметки» — прокрутка списка.

### Меню в трее
Вид острова (капсула / чёлка) · Скрывать в полноэкранных приложениях · Задержка закрытия ·
Уведомления (+ тест) · Загрузки · Выбор города · Автозапуск · Выход.
Настройки хранятся в `%APPDATA%\WinIsland\settings.json`.

## ⬇️ Точные загрузки из браузера (по желанию)

Без расширения остров «угадывает» загрузки по папке «Загрузки» (процент неизвестен, видно размер и скорость).
С расширением показывает **точный процент** для Chrome, Edge, Яндекс Браузера, Opera, Brave, Vivaldi:

1. Откройте `chrome://extensions` (в Яндексе — `browser://extensions`, в Edge — `edge://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `browser_extension`.

Расширение шлёт данные только на `127.0.0.1` (ваш же компьютер) — в интернет ничего не уходит.

## 🔒 Приватность и ограничения

- **Telegram и уведомления.** По умолчанию Telegram Desktop рисует **свои** баннеры и в Windows их не отправляет — поэтому остров их не видит.
  Откройте в Telegram *Настройки → Уведомления* и включите пункт про **системные (нативные) уведомления Windows**
  (по-английски *Native notifications*). Проверить, что всё работает, можно кнопкой **«Проверить уведомления»** в меню трея.
- **Уведомления.** WinIsland читает локальную базу уведомлений Windows (`wpndatabase.db`) — это неофициальный способ, он может перестать работать после обновления Windows. Текст уведомлений никуда не отправляется. Обычные всплывашки Windows справа всё равно показываются; чтобы остался только остров — отключите баннеры нужного приложения в *Параметры → Система → Уведомления*.
- **Wi-Fi / Bluetooth / режим полёта** работают через системный API радиомодулей Windows; «режим полёта» — это выключение всех радиомодулей, а не системная кнопка.
- **Яркость** доступна только на экранах, которые это поддерживают (ноутбуки и часть мониторов).
- Погода: [Open-Meteo](https://open-meteo.com/) (бесплатно, без ключей). Определение города по IP — через ip-api.com.
